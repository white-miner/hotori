# 업무 팝업 상단 탭 전환 및 검증

검증일: 2026-10-31 KST. 기준 main: dce9afa. UI 우선 대상: 단체 관리에서 이어지는 긴 조회·입력·정정 창.

## 기획과 적용 범위

- 단체·대표객실 관리: 요약 / 연결 객실·대표 / 청구 근거 / 결제 내역 / 변경 기록. 결제 등록, 일정·요금 수정, 결제 기록 정정은 고정된 상단 바로가기에서 기존 실제 업무창을 연다.
- 단체 결제 등록: 결제 등록 / 청구 근거 / 결제 내역 / 객실 관리. 조회 탭에서는 등록 실행 버튼 대신 등록 탭으로 돌아가는 버튼을 제공한다.
- 기록 정정: 결제 내역·정정 / 객실 일정·요금 / 변경 이력. 객실 요금으로 직접 진입하면 해당 탭과 편집 줄을 바로 연다.
- 단체 일정·요금 수정: 객실별 일정·요금 / 날짜별 객실 수 / 변경 확인. 저장 전 객실별 일정·총액 변화와 기존 수납·배정 유지 안내를 확인한다.
- 수납 데스크: 수납·선금 / 할증 / 잔액 사용 / 결제 내역. 지원하는 업무만 표시한다.
- 공통: 제목·탭·저장/닫기는 고정, 선택한 본문만 스크롤. 탭 전환은 저장하지 않는다. 숨긴 패널을 유지하여 편집 초안을 보존한다. 방향키/Home/End, 탭-패널 ARIA 연결을 제공한다.

단순 확인창과 이미 목적 탭을 갖춘 객실 업무창에는 불필요한 탭을 추가하지 않았다. 신규/간단 예약, 신규 단체 등록, 전체 설정 화면은 이번 변경 대상에 포함하지 않는다. 향후 같은 공통 컴포넌트로 확장할 수 있다.

## 브라우저 검증

실제 수정 컴포넌트를 렌더링하는 메모리 전용 검증 화면에서 다음을 확인했다. 운영 DB에는 연결하지 않았다.

- 단체 조회 탭마다 해당 데이터만 표시. 상단 결제 등록·일정 수정·기록 정정이 실제 대상 컴포넌트를 연다.
- 등록 금액 90,000원과 메모를 입력하고 탭 왕복·재조회 후 유지. 조회 탭에서 등록 실행 버튼 미노출.
- 저장 실패를 주입해 오류·초안 유지 확인. 재시도 성공 후 미수금 230,000 → 140,000원. 방금 등록 취소 후 230,000원으로 복원.
- 기록 정정에서 카드 50,000 → 60,000원 초안 입력, 탭 왕복·재조회 후 유지, 저장 후 정확한 해당 결제 줄과 합계 반영.
- 검증102호만 1박 연장, 신규 박 요금 90,000원 입력. 일별 집계 및 변경 확인에서 150,000 → 240,000원. 탭 왕복·재조회 후 유지. 저장 후 배정 및 수납 160,000원 보존, 청구 380,000 → 470,000원.
- 수납 데스크에서 수납 12,345원과 할증 20,000원 초안이 독립 보존. 재조회 후 선택 모드·금액 유지. 잔액 사용 중 보관 잔액이 소진되면 수납 탭으로 복귀하며 기존 45,678원 초안 보존.
- 774×712: 머리글·탭·하단 닫기 화면 안에 유지. 본문 스크롤 후 탭 위치 78px, 하단 690px 유지. 탭 전환 시 본문 스크롤 0으로 초기화.
- 1920×1080: 조회·업무 바로가기 한눈에 표시. 방향키로 인접 탭 선택·포커스 이동 확인.

실제 로컬 현황판의 오서(G30)에서 단체 관리 → 결제 내역 → 결제 등록, 일정·요금 수정, 결제 기록 정정 연결을 열고 닫아 확인했다. 실제 결제 합계 1,700,000원 및 이체/카드 3개 기록이 표시됐다. 운영 예약·수납·대표 지정·일정은 변경하지 않았다. 사용자에게 열려 있던 기존 작업 탭은 그대로 유지했다.

## 남은 범위와 제한

- 운영 데이터의 저장·삭제·취소를 테스트 목적으로 실행하지 않았다. 저장 실패·성공·되돌리기는 메모리 화면에서 검증했고 실제 화면은 조회·진입·닫기를 확인했다.
- 개별 탭 내부의 객실/결제 목록이 길면 해당 목록의 스크롤은 유지한다. 모든 데이터나 모든 편집 필드를 한 화면에 축소해 넣지 않는다.
- 기록 정정창의 기존 닫기 동작과 저장 API는 유지했다. 탭 이동과 전체 창 닫기는 구분되며 창 닫기 후 초안을 복구하는 기능을 새로 추가하지 않았다.
