## 1. 무엇을 위한 앱인가요

호토리는 **손으로 적는 예약 장부(가계부)**예요. 야놀자, 여기어때, 아고다 같은 여러 플랫폼에서 들어온 예약을 직원이 직접 적어요.

목표는 두 가지예요.
1. **오버부킹 막기**: 같은 날, 같은 타입이 가진 방보다 많이 팔리지 않게 해요.
2. **공실 막기**: 남은 방이 보이니까 메인 플랫폼에서 재고를 제때 열고 닫을 수 있어요.

남은 객실은 **날짜별·타입별 숫자**로 크게 보여 줘요. 직원은 그 숫자를 보고 메인 플랫폼에서 재고를 직접 조정해요. 플랫폼마다 몇 개씩 열었는지는 적지 않아요.

원칙은 세 가지예요. **빨리 적고, 빨리 고치고, 한눈에 봐요.**

## 2. 넣는 것 / 넣지 않는 것

| 넣어요 | 넣지 않아요 |
|---|---|
| 숙박 예약 기록·수정·취소 | 청소 상태, 점검 상태 |
| 대실 기록 (시간 범위 필수) | 체크인·퇴실 처리 화면, 남은 시간 타이머 |
| 날짜×타입별 남은 객실, 오버부킹 경고 | 외부 플랫폼 연동, 자동 재고 동기화 |
| 화이트보드 같은 방 번호 보드 (방 배정은 선택) | 자동화, 알림 발송 |
| ◯ 입실 표시 (한 번 누르기, 선택) | 플랫폼별 재고 수량 기록 |
| 설정: 층·방 번호·객실 타입·플랫폼 | 매출 분석 대시보드, 큰 매출 카드 |
| Free / Pro 구독 표시 | (결제 연동은 검증 뒤에 붙여요) |

## 3. 기록하는 내용 (예약 1건)

| 항목 | 필수 | 설명 |
|---|---|---|
| 종류 | ● | 숙박 / 대실 |
| 플랫폼 | ● | 설정에 등록한 플랫폼 중 하나 (한 글자 약자: 야, 여, 아, 부…) |
| 판매가격 | ● | 원 단위. 숙박은 **총액**으로 적고, 1박 평균은 자동으로 보여 줘요 (질문 2) |
| 이름 | ● | 손님 이름 |
| 객실 타입 | ● | 설정에 등록한 타입 (예: S 스탠다드) |
| 입실 날짜 | ● | 기본값은 오늘 |
| 박수 | ● (숙박) | 1박부터. 퇴실 날짜는 자동 계산 |
| 시간 범위 | ● (대실) | 예: 12:00~14:00. 대실은 시간 없이 저장할 수 없어요 |
| 방 번호 | 선택 | 비워 두면 '방을 아직 안 정한 숙박'에 모여요 |
| ◯ 입실 | 선택 | 한 번 누르면 켜지고, 다시 누르면 꺼져요 |
| 메모 | 선택 | 짧은 메모 한 줄 |
| 취소 여부 | – | 취소하면 장부에는 줄을 그어 남기고, 남은 객실 계산에서는 빠져요 |

자동 기록: 누가, 언제 적고 고쳤는지 남겨요.

## 4. 남은 객실 계산 규칙

**남은 객실(타입, 날짜) = 그 타입 전체 방 수 − 그날 밤을 차지한 숙박 예약 수**

- 숙박 예약은 **입실 날짜부터 박수만큼의 밤**을 차지해요.
- **퇴실하는 날 밤은 비어요.** 그래서 같은 날 다른 손님에게 다시 팔 수 있어요.
- 대실은 **남은 객실 계산에 넣지 않아요.** 시간 범위만 따로 보여 줘요.
- 취소한 예약은 계산에서 빠져요.
- 오버부킹은 **타입 기준**으로 판단해요. 그 타입이 판 숫자가 방 수보다 많으면 오버부킹이에요.

**표시 규칙**

| 남은 객실 | 표시 |
|---|---|
| 3 이상 | 보통 숫자 (여유) |
| 1~2 | 진한 회색 칸 '적음' (방이 4실 이상인 타입만. 기준은 설정에서 바꿀 수 있어요) |
| 0 | 빨간 테두리 '만실' |
| 마이너스 | 빨간 칸 '초과' = 오버부킹. 맨 위 문장에도 "10/24(토) 스탠다드 디럭스 1실 초과"처럼 알려 줘요 |

**예시** (S 스탠다드 14실이라고 할 때)

| 예약 | 차지하는 밤 | 다시 팔 수 있는 날 |
|---|---|---|
| 10/18 입실 3박 (3박4일) | 10/18, 10/19, 10/20 | 10/21 밤부터 |
| 10/18 입실 1박 | 10/18 | 10/19 밤부터 |
| 10/18 대실 12:00~14:00 | 없음 (계산 안 함) | – |

- 10/19 밤에 S 숙박이 13건이면 → 남은 객실 **1** (적음)
- 14건이면 → **0** (만실, 메인 플랫폼에서 S를 마감해야 해요)
- 15건이면 → **−1** (초과 = 오버부킹. 한 건은 다른 타입으로 옮기거나 연락해야 해요)

## 5. 화면 (4개)

### ① 현황판 (메인) — `png/1-PC-현황판.png`, `png/3-모바일-현황판.png`
- **위쪽: 앞으로 14일 남은 객실 표.** 날짜는 가로, 타입은 세로예요. 숫자를 크게 보여 줘요. 맨 아래 줄은 전체 남은 방이에요.
- 맨 위 한 문장: 오버부킹이 있으면 가장 가까운 날짜를 빨간 글자로 알려 줘요. 없으면 "오버부킹 없어요".
- 날짜 칸을 누르면 그날이 선택돼요.
- **아래쪽: 방 번호 보드.** 화이트보드처럼 6층·5층·3층·2층·방갈로가 같은 순서로 놓여 있어요. 칸마다 그날 밤 예약 메모(플랫폼 약자, 이름, 가격, 몇 박 중 며칠째, ◯)를 보여 줘요. 빈 방은 점선 칸이에요.
- **오른쪽: 그날 대실 목록**(시간 범위 순서)과 **방을 아직 안 정한 숙박**이 있어요. [방 정하기]를 누르면 빈 방을 골라요.
- 모바일: 7일 표 + 층별 방 칸(층 칩으로 바꿔 보기) + 오른쪽 아래 [+ 기록] 버튼. 아래쪽 탭바는 쓰지 않아요.

### ② 예약 기록·수정 — `png/2-PC-빠른기록.png`, `png/4-모바일-빠른기록.png`
- 어디서든 **N 키**나 [+ 예약 기록]으로 열려요. 커서는 바로 이름 칸에 있어요.
- 플랫폼 칩(숫자 1~8), 객실 타입 칩(Q W E R T), 입실 날짜 칩(오늘/내일/모레/날짜 고르기), 박수 −/+ (←→), 이름·가격, 방 번호(그 기간에 빈 방만 보여요).
- 타입 칩마다 그 날짜의 남은 객실이 같이 보여요.
- **저장하기 전에 바로 보여 줘요:** "10/18(일) S 남은 객실 4 → 3". 0이 되면 "만실이 돼요"라고 알려 줘요.
- Enter 저장, Ctrl+Enter 저장하고 하나 더, Esc 닫기.
- 숙박/대실을 바꾸면 박수 대신 시간 범위(시작~끝) 칸이 나와요.
- 수정도 같은 창을 써요. 방 칸이나 장부 줄을 누르면 열려요.

### ③ 장부 목록·검색 (시안은 이번에 그리지 않았어요)
- 표 한 줄 = 예약 한 건: 입실 날짜, 플랫폼, 이름, 타입, 박수, 방, 가격, ◯.
- 이름·플랫폼 검색(/ 키), 날짜 범위, 플랫폼·타입 필터.
- 취소한 예약은 줄을 그어 남겨요. 엑셀 내보내기는 Pro로 제안해요.

### ④ 설정 — `png/5-PC-설정.png`
- **객실 배치:** 층 줄마다 방 번호를 추가해요. 위에서 타입을 고른 뒤 방을 누르면 그 타입으로 바뀌어요.
- **객실 타입:** 코드(최대 3글자, 예: S, T, SD, TD)와 이름. 방 수는 자동으로 세요.
- **플랫폼:** 이름, 한 글자 약자, 순서. 순서대로 단축키 1~8이 붙어요.
- 요금제, 직원 계정.

### 디자인 원칙 (조용한 색)
- 흰 바탕, 연한 회색(#F2F2F2) 둥근 칸, 거의 검은 글자(#1A1A1A), 회색 보조 글자(#6B6B6B).
- 강조색은 **빨강 하나(#E0242F)**만 써요. 만실·초과와 주요 버튼(저장, + 예약 기록)에만 써요.
- 타입·플랫폼은 색으로 나누지 않고 짧은 코드와 한 글자 약자로 구분해요.
- 모서리는 14~26px로 둥글게, 여백은 넉넉하게. 물결무늬는 뺐고, 브랜드 표시는 작은 빨간 세로 도장 '호토리' + HOTORI 글자만 남겼어요.
- 경쟁 앱에서 흔한 검정 매출 카드, 상태 숫자 4칸, 아래쪽 5칸 탭바는 쓰지 않아요.

## 8. 확인하고 싶은 것 (5개)

1. **업그레이드 배정:** S로 팔았는데 SD 방에 넣으면, 남은 객실은 어느 타입에서 빼야 할까요? (제안: 방을 정하면 **실제 들어간 방의 타입**에서 빼고, 방을 안 정했으면 판 타입에서 빼요.)
2. **판매가격:** 연박일 때 총액으로 적으세요, 1박 가격으로 적으세요? (제안: 총액으로 적고 1박 평균을 자동으로 보여 줘요.)
3. **방갈로:** 방갈로를 따로 타입 1실로 둘까요, 다른 타입에 넣을까요? (시안은 'BG 방갈로' 1실로 했어요.)
4. **취소·노쇼:** 취소한 예약은 장부에 줄을 그어 남기고 남은 객실에서만 빼면 될까요?
5. **같이 쓰는 사람:** 프런트 PC 말고 사장님 폰 등 여러 기기에서 동시에 쓰시나요? (동시 사용을 Free에 넣을지 Pro에 넣을지가 정해져요.)
