# 객실카드 사양 (단일 문서)

이 문서가 객실카드의 유일한 기준이에요. 코드는 `shared/roomCard.ts`의 `roomCardModel` 하나가 만들고,
현황(`nowCell`) 하나가 이 값을 써요(배치 화면은 현황에 합쳐졌어요). 검증 사례표는 `shared/roomCardCases.ts`, 테스트는 `src/roomCard.test.tsx`.

## 1. 개념 (기준 사진: StaySync 객실 화면, 사용자 제공 2026-10-28)
사진에서 읽은 것만 적어요.
- 카드 = 그 객실, 그 날짜의 상태 한 장. 객실 하나 = 카드 하나. 예약이 없으면 "예약 없음" 빈 카드.
- 카드 안에서 한눈에: N/M박(오늘이 몇째 밤/전체 박수), 손님 이름, 체크인·체크아웃, 객실 가격, 결제방식, 예약 경로(현장·야놀자…).
- 상태는 색·테두리(입실 전 회색, 입실 진한 색, 점선=플랫폼 예약 등). 입실·퇴실·수정 같은 동작은 카드에서 바로.
- 같은 손님의 여러 객실은 (1/3), (2/3)처럼 묶음 표시. 자세한 값은 카드를 눌러 상세에서.

> 카드에는 메모 줄이 없어요(사용자 확정 2026-10-28). 메모는 저장된 그대로 두고 옆 패널·수정 화면에서 봐요.

## 2. 표시 순서 (확정)
1. 객실번호 (건물 이름은 붙이지 않음 — 건물별 화면이 따로 있어요)
2. 이용기간 + 박수: `10/27~10/29 · 2/3박`, 1박 `10/28 · 1박`, 입실 전 `10/30~10/31 · 2박`(몇째 밤 숨김)
3. 결제 방식·금액: 현금/카드/이체 + 받은 돈, 플랫폼 예약은 플랫폼 이름 + 판매금액(`야놀자270,000`)
4. 손님 이름
5. 회사
6. 박당 요금

화면 배치: `RoomCardFacts` 슬롯 top(기간·연동·결제·받을 돈) → 이름 → who(회사·박당 요금). 현황과 배치가 같아요. **한 사실 = 한 줄**(칩을 쌓지 않음). 모든 줄은 자기 자리(슬롯)가 고정이고 한 줄 줄임표예요 — §11.

- 카드 높이: 행 최소 200px 그대로 (줄이 늘어도 한 줄씩이라 비슷해요). 화면 확인용 그림은 진짜 Dashboard + 진짜 CSS + 가짜 데이터로 headless Chrome에서 찍어요 (하네스는 git 무시 폴더라 `/workspace/card-render/harness-src`).

## 3. 색
| 값 | 색 | 클래스 |
|---|---|---|
| 객실 가격(박당 `₩…/박`) | 빨강 | `rc-rate amt-rate` |

## 4. 단체
- "대표객실" 글자와 단체 결제(이체·카드 등)는 대표객실 카드에만.
- 구성원 카드: 객실번호, 이용기간, `연동 본관 602호`(건물+호수, 작게), 자기 플랫폼 판매금액 한 줄(플랫폼 이름+금액, 있을 때만), 자기 박당 요금. 단체 이체·카드·미수금·이름·회사는 안 그려요.
- 활성 객실이 1개뿐인 단체, 장기숙박은 개인 카드처럼.
- 대표객실 표식을 누르면(마우스 올리면) 연동된 객실 목록.
- **건물+호수(예: 본관 602호)는 다른 객실을 가리킬 때만**: 구성원 카드의 대표객실 표시, 대표객실의 연동 객실 목록. (건물이 2개 이상인 호텔만; 일반 카드에는 건물 이름 없음)

## 5. 금지
- 플랫폼 예약번호는 카드에 표시하지 않음.
- 평균·추정·총액 나누기 금지. 박별 요금이 있으면 그 날 값, 없으면 정해진 값만. 없으면 비움.
- 박마다 다르면 "변동" 표시.
- 퇴실 미정은 `10/25 ~` (몇째 밤은 `4박째`).

## 6. 박당 요금 우선순위 (`nowNightRate`)
1. 보는 날짜에 입력된 박별 요금
2. 예약의 고정 박당 요금(flat)
3. 1박이면 객실 가격
4. 없으면 표시 안 함(평균 계산 안 함)

## 10. 고정 크기 (현황 `nowCell`)
카드는 **크기가 고정된 틀**이고 내용이 그 틀을 채워요. 내용이 틀의 크기를 바꾸지 않아요.
- 높이: `:root { --room-card-h: 278px }` 하나 (사용자 허락 2026-10-28로 256 → 278: 결제 줄 두 줄 + 줄 높이 여유). 데스크톱·모바일 모두 같은 값. 격자 `grid-auto-rows: var(--room-card-h)`, `.cell { height: var(--room-card-h); min-height: 0 }`. `minmax(…, auto)`·`min-height` 로 늘어나던 규칙은 제거.
- 가로: 한 줄의 칸 수에 맞춰 `1fr` 균등 분할 — 모든 카드가 같은 폭. 데스크톱 최소 폭 `minmax(208px,1fr)`(이전 168px, 결제 줄이 잘리던 원인), 모바일(≤760px)은 `minmax(140px,1fr)` 2열 그대로.
- 대상: 대표객실·단체 구성원·개인·플랫폼(OTA)·퇴실 미정·빈 칸·점검 칸 전부 같은 크기.
- 빈 칸: 객실번호 + 유형 아래 회색 이탤릭 `예약 없음` (현황 `공실`, 옛 배치 `빈 방` 문구를 대체). 점검·보류·같은 타입(이동 모드) 문구는 그대로.
- 없는 내용은 빈 자리로 두고(줄을 만들지도 없애지도 않음 — §11), 넘치는 내용은 자리 안에서 한 줄로 잘라요: 이름·회사는 한 줄 말줄임(`…`), 결제 줄은 두 줄까지(그 뒤 `…`), 나머지는 `overflow:hidden`. 머리(객실번호·유형)·이용기간 줄·하단 상태 칸은 줄지 않아요(팝오버·마크가 걸려 있어서 `.cell` 자체에는 `overflow:hidden` 을 걸지 않음).
- 측정(하니스, 헤드리스 크롬): 21사례 + 긴 이름/회사 사례 + 빈 칸 전부 한 격자에서 모든 `.cell` 의 가로·세로가 같음. 가로는 브라우저의 1/64px 반올림(≤0.02px) 차이만 있음.

## 11. 슬롯(고정 자리) — 현황 `nowCell`
카드는 **칸 구조가 먼저 있는 틀**이에요 (사용자 지시 2026-10-28: "어떤 내용이 들어가든 카드 내부 줄이 바뀌면 안 된다. 모든 정보는 고유한 자리값이 있고, 값이 새로 생성되는 게 아니라 만들어진 자리에 값이 끼워진다").
- 줄마다 자기 자리(`data-slot="…"`)가 **항상** 그려져요. 값이 없으면 자리는 비어 있을 뿐이고, 줄이 생기거나 없어지지 않아요. 구성원·미결제·회사 없음·요금 없음·빈 칸·취소 모두 같은 자리.
- 자리는 CSS Grid 명시 행(`grid-template-rows` px) + 자리마다 `grid-row` 하나. 그래서 모든 카드에서 같은 자리의 위 거리가 같아요 (하니스 측정: 편차 0px).
- 모든 자리는 한 줄 + 넘치면 줄임표/잘림. 단 결제 줄(`이체 100,000 · 카드 50,000 …`)은 자리 높이 32px 안에서 두 줄까지(`-webkit-line-clamp:2`), 한 줄이면 아래(받을 돈 쪽)에 붙어요. 자리 높이가 정해져 있어 아래 줄을 밀지 않아요.
- 높이 변수(`:root --rc-h-*`, styles.css 맨 아래)와 합계: 위아래 여백 2+2px + 테두리 안에서 카드 높이 `--room-card-h`(278px)를 넘지 않아요 (테스트가 합계를 검사).
- 덮어쓰기 규칙: 이전 `.cell` / `.now-page .cell` / `.board-page … .cell` 규칙들이 줄마다 위아래 margin·padding·높이를 따로 줘서, 자리의 **세로 기하(margin·padding·height·line-height)만** `!important` 로 고정했어요. 가로 padding·글자 크기·색은 그대로.

## 12. 카드 고침 (2026-10-28, 사용자 확정 진단 7가지)
측정은 하니스(1440 / 1024, 헤드리스 크롬)로 했고, 고침 뒤 칸 잘림 0 · 가로 스크롤 0 · 달력 팝오버가 이웃 카드 위로 새는 곳 0 이에요 (긴 이름·회사의 한 줄 줄임표는 의도한 동작).
1. **결제 줄 잘림 · 7. 좁은 폭**: 카드 최소 폭 168 → 208px, 결제 자리 두 줄 허용 (§10·§11). 1024px에서는 3열 → 2열(카드 폭 284px)이 돼요.
2. **머리 줄 말풍선 잘림**: `.grp-no-hit`·`.nowmemo`·`.grp-lead-tag` 가 줄어들 수 있게(`min-width:0` · `max-width`) 하고, 객실번호는 줄지 않게(`flex:0 0 auto`).
3. **머리·유형·이름 자리 잘림**: 머리 36→38, 유형 15→17, 이름 23→27 (이름 자리 안 `.pb` 가 26.4px), 받을 돈 17→18, 박당 요금 20→21. 늘어난 만큼 카드 높이를 256→278로 키워 합계가 `--room-card-h` 안에 있어요.
4. **단체 카드 왼쪽 이중선**: 줄무늬(`inset 4px`)와 안쪽 테두리 링을 `box-shadow` 한 목록으로 합치고, 왼쪽 테두리 색을 줄무늬 색(`--grp-c`, g1~g6)과 같게 했어요 (이전에는 붉은 1.5px 테두리 + 파란 4px 줄무늬가 겹침). 퇴실 지연(`.ncx`) 카드는 오른쪽 붉은 줄을 같이 그려요.
5. **달력 팝오버가 이웃 카드 위로 번짐**: 팝오버를 `document.body` 로 포탈 + `position:fixed`(z-index 60). 날짜 줄 아래에 놓고, 화면 아래로 넘치면 위로 뒤집고, 좌우는 화면 안으로 맞춰요. 창 크기·스크롤이 바뀌면 다시 놓아요.
6. **자리 높이 재분배**: §11 표.
